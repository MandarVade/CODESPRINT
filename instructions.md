# CodeSprint 2026

### Solve • Code • Submit

Welcome to **CodeSprint 2026**, an offline coding competition designed to test your problem-solving, programming, and algorithmic skills.

---

## Competition Format

* You will be provided with **10 coding problems**.
* The problems are divided into **Java and SQL** sections.
* You must solve each problem according to the programming language specified for that problem.
* Each problem contains a clear problem statement, required method/query, examples, and constraints.
* Test cases will be used during evaluation.
* Internet access will be **strictly disabled** throughout the competition.

---

## System Rules

* No internet connectivity will be provided.
* Browser access should not be used.
* AI tools, ChatGPT, GitHub Copilot, or other assistant-type tools are strictly prohibited.
* Only the tools provided by the organizers are allowed.
* External libraries or software must not be installed during the competition.
* Use the provided local compiler, interpreter, database, and development tools.

---

## Submission Rules

* Solve the problems by editing the provided solution files.
* Save your final solution in the original file.
* Do **not** rename the folders or files.
* Do **not** modify the problem statements.
* Do **not** modify the test files.
* Make sure your solution compiles and works with the provided examples before submission.
* Submit the complete project folder at the end of the competition.
* Only one submission per participant/team will be accepted.

---

## Java Problems

For Java problems:

* Use the class name provided in the problem.
* Use the exact method name and method signature specified in the problem.
* Do not change the required return type or parameters.
* Your solution must compile successfully.
* Do not modify the provided `Test...java` files.
* The evaluator will automatically run your solution against 10 test cases.
* Each passed test case gives **1 point**.

---

## SQL Problems

For SQL problems:

* Write the SQL query required by the problem.
* Use the tables and columns specified in the problem statement.
* Do not modify the database or test data.
* Do not change the required output columns unless the problem explicitly allows it.
* Your query will be executed against the test database.
* The result will be compared with the expected result.
* Each passed test case gives **1 point**.

---

## Competition Rules

* Solve all assigned problems according to their specified language.
* **No negative marking.**
* Marks are awarded based on the number of test cases passed.
* Wrong answers, compilation errors, runtime errors, or timeouts receive **0 points** for that test case.
* Do not modify test cases or evaluation files.
* Do not modify the problem statement to change the requirements.
* Do not replace the required method or query with a different interface.
* Cheating, copying, or using prohibited external assistance will result in disqualification.
* If you face a system or file-related issue, inform the volunteers immediately.
* You may ask volunteers for clarification about the problem statement or system issues, but not for solutions or hints.

---

## Important

Before submitting:

* Check that all required files are present.
* Check that Java programs compile correctly.
* Check that SQL queries execute correctly.
* Check that class names and method signatures have not been changed.
* Do not edit any `Test...java` files.
* Do not edit the evaluation files.
* Do not rename files or folders.

---

## Doubts / Assistance

For non-technical issues such as file problems, system crashes, missing files, or environment issues, contact the volunteers.

Volunteers may clarify the problem statement or resolve system issues, but will not provide solutions or hints.
